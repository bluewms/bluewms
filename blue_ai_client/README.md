# 宝蓝 AI 云端连接

> 2026-10-16：通用示例、知识说明与 Skill 正文统一云端管理；本地保留合同、策略代码及验证发布。共享资料已配置，Odoo 只读知识桥接、按入口选 Task、模板解耦仍待实现。见 [配置与实施基线](../docs/architecture/cloud-knowledge-and-ai-workflow.md)。

`blue_ai_client` 为 MuK AI 添加 Chat Completions provider 和代码资产工具，不修改 MuK 上游文件。

## 设置

MuK AI → 设置 → 宝蓝云端服务：启用连接、填写服务地址及模型。

MuK AI → 配置 → 宝蓝用户连接：管理员为每个内部用户填写其业务用户 API Key 和准确的云端 Agent 名称。当前管理员也可以直接在设置页修改自己的连接。

- 当前实现仍固定团队 `odooAI`、任务 `日常任务`。云端已建立五类业务 Task，兼容任务保留；客户端按 hook 路由尚未实现。
- 默认入口 `https://odooapi.royalblue56.com/codebuddy/default`，自动补齐 `/v1/chat/completions`；也接受完整端点。
- 默认模型 `glm-5.3-Flash`；输入窗口按 supplied catalogue 为 1048576，初始每次输出限制为 8192，可在 provider 管理界面调整。
- 安装时不写入任何真实 Key，默认禁用 provider。测试连接会调用模型（最多 512 输出 token），请在确认配置后点击。
- 不展示剩余额度，不维护本地充值/扣费账本。MuK 原有 token/费用统计不代表云端实际扣费，初始模型费率为 0，需由服务方确认后维护。

API Key 字段限制管理员读取；运行时只读取当前用户的固定连接。普通用户不能更改 Agent 或借用其他用户的 Key。没有连接的用户直接报错，不使用管理员凭据兜底。

## 腾讯代理初始化

当前代理入口不公开 Metadata API，不能直接通过名称查询 ID。本模块按代理返回的初始化表单自动完成选择，保留 option 中的真实标识后缀；模型不会参与选择用户身份。

仅识别 `session-init-*` 响应和 `call_session_init_* / ask_followup_question` 工具；自动选择“是，关联团队资产”、`odooAI`、用户配置的 Agent、`日常任务`。缺失、重名、未知字段、超出轮次均报错，不跳过资产注入、不选默认替代项。普通模型发出的同名工具不会被自动执行。

`x-conversation-id` 和 `session-id` 稳定关联 MuK 会话；改变用户 Key 或 Agent 名称会得到新的代理会话标识。最多六次 HTTP 初始化/模型调用，避免无限循环。协议依赖当前腾讯 CodeBuddy 表单约定，代理升级后需回归。

## 代码生成

代码资产页面点击“AI 生成 / 修改”打开已有 MuK 聊天，并自动选择宝蓝代码助手。普通聊天如需使用宝蓝连接，可在 MuK 原有默认设置选择宝蓝云端；模块不自动覆盖公司已有默认服务和智能体。首期业务流程由 MuK 的工具循环驱动；云端代理负责模型转发、记忆/技能注入和用户隔离，不在两端各跑一套工具执行循环。

三个本地工具只操作当前会话绑定的资产：

1. `blue_read_code_asset` 返回绑定资产的当前草稿、接口版本标识、测试及摘要，兼容返回本地模板示例；当前没有完整返回机器可读接口规范，也未改为从云端自动读取示例。
2. `blue_submit_code_draft` 调用既有草稿入口，检查草稿摘要和正式基础版本，记录 AI 来源。
3. `blue_validate_code_draft` 调用已有试算/验证，失败原因回到聊天供修复。

工具按实际用户权限执行，不 sudo 写业务数据、不直接执行生成 Python、不提供发布或 shell 工具。验证成功后用户在资产页面审阅并发布；手工编辑或正式版本变化后旧会话拒绝覆盖，应重新从页面打开 AI。

云端 Skill／Wiki 依赖 CodeBuddy shell/curl 的加载说明与当前 Odoo 工具不兼容。需实现服务端正文注入或受限只读桥接，按身份／批准状态／版本读取正文与资源，限制 URL、路径、大小和超时；本模块不提供任意命令执行。停止本地示例回传前须拆开 template_id 承载的运行定义和示例内容，保留旧正式版本与绑定。知识/技能质量、未加载的云端资产以及其他用户的真实身份需要单独验收。

## 检查

独立数据库执行 `/blue_ai_client` 后端测试，覆盖协议与流式解析、初始化选项、私密字段、用户隔离、权限、草稿并发、正式版本冲突、验证与 MuK 多轮工具闭环。部署和真实联调证据见 `docs/third-party/blue-ai-client-install-2026-10-13.md`。
