# BlueWMS 条码作业

Odoo 20 首版. 首页提供作业、盘库、产品和位置入口. 产品/位置查询只读;单据和批次按位置组合或源/目的包裹分组分页,保留真实单据与明细归属.

使用独立全屏条码终端,按仓库/作业类型选单,批次作业使用相同分页. 产品行有图片、已扫/需求量、选中高亮及快捷加减/补齐剩余;独立数字键盘编辑总数,使用原有受控计数事件保存. 刷新恢复所在页和选中行,详情返回保留作业. UI 采用当前 Odoo 20 原生图标与 MuK 主题变量. 16 版操作对照见 `docs/guides/barcode.md`.

PDA 作业不显示条码输入框,直接通过 Odoo 的 barcode_scanned 事件驱动;保留相机. 采集保留完整二维码,支持结束符或空闲边界,移动端复用原生隐藏输入. 产品/位置提供资料和可相互进入的库存详情,从作业查看资料后可以返回并保留扫描进度. 条码配置在既有同一组页签中;安装 WCS 桥接时排在 WCS 后.

扫描事件在服务端与数量修改同事务保存. 同次请求重试不重复加数,真实重复扫描可累计. 预留数量不冒充已扫描量. 支持手工总数、批次/序列号补扫、获准的新批次创建、包装单位换算、原生 GS1、获准的本组装箱及原生库存验证. 同单多终端写入须明确交接;外部修改、能力配置变化、超量、追踪歧义及旧版本停止并提示核对.

不安装桥接时盘库入口提示安装和建单,不会回落为任意 quant 调整. 样式使用 Odoo/MuK 主题变量;无 MuK 硬依赖. 队列暂停后保留未确认事件和后续输入,服务不可达时不承诺完整离线作业.

19 版操作补充见 `docs/guides/barcode.md`: 验证进度及剩余量核对、原生欠单向导与完成页、固定打印/标签入口、人工取消及常用操作码. 预留量不准代替扫码验证,完成后不再计数;原生退货从完成单据进入.

本模块未实现旧版 RFID/EPC、报废、签名等附加页面. 旧版本数据与开放会话不自动迁移. 实机扫码枪/PDA、相机权限及现场编码格式需单独验收. 安装状态、源码和验证见 `docs/guides/barcode.md`.
