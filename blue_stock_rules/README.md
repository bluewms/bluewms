# BlueWMS 库存规则

适用于 Odoo 20, 依赖 blue_stock_base。安装后默认保护库存产品在内部／中转位置的非负在手量, 并使“是否锁定”具有冻结进出和新增预留的实际后端约束。

在位置上区分“是否锁定”和“禁止入库”: 前者冻结进出, 后者仅阻止入库。设置作用于下级位置; 取消作业和释放预留仍可执行。通过产品、类别、位置上的“允许负库存”配置明确例外, 产品／类别设置须由有相应模型写权限的库存管理员修改。

不允许客户端 context 绕过检查。已完成库存移动不会因修改规则而自动撤销, 也不会自动修改历史负库存。

来源、许可、精度、权限、测试及边界见 [交付记录](../docs/migrations/stock-rules-20.md)。同批次／同单上架未包含在本模块中。
