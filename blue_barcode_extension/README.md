# BlueWMS AI 条码扫描规则

barcode_policy/1 提供 parse/decide 两阶段纯数据合同. between(raw, separator, start, end) 按 1 起算的分隔符出现次数取值,保留空字段. 不开放通用 split、正则、ORM、网络、eval 或任意 JavaScript.

作业类型“条码”页可以打开/新建代码资产,使用既有“条码扫描策略”Task 生成或修改草稿,准确试算并人工发布. 公司可绑定通用解析配置供首页和盘库使用. 扫描会话固定已发布版本,不逐枪调用模型;已绑定但未发布或无效时停止.

decide 选择一条真实候选或提示补扫,并可请求 next_group/wcs/validate/pack 后续注册动作. 本地复核授权和库存规则,先保存扫码再执行后续操作. 当前 /1 不接受一次跨多行自动数量分摊.

本地合同/资产/准确试算已有隔离库验证. docs/wiki 中规范和完整案例需独立云端批准及发布后才能进行真实联网生成,Git 合并和安装不自动发布知识或客户策略.
