# 条码验收清单

适用当前 blue_barcode_base 及盘库/AI/WCS 桥接模块. 业务用法见[条码指南](../guides/barcode.md), 自动回归保存在各模块 tests/, 键盘采集和独立事务工具见[scripts 说明](../../scripts/README.md).

此表定义核对项, 不等于本轮已在客户设备执行. 自动用例、真实单据和 PDA/相机现场结果分别记录.

| 场景 | 当前预期 |
|---|---|
| 预留量与已扫量 | 预留不冒充已扫, 首次有效扫码从未确认状态累计; 实盘首次从零累计 |
| 重复扫描与请求重试 | 两次真实扫描可累计; 相同事件重试复用结果, 不重加数量 |
| 商品与单位 | 普通商品码和已配置包装单位按原生换算, 超收受作业类型授权限制 |
| 标准码与 QR | 完整原文交解析器, 保留前导零、空段和 GS1 分隔符; 已声明格式错误不回落为商品加1 |
| 重码与多明细 | 产品/位置/批次/包裹有歧义时拒绝或明确选择, 不默认取第一条、不跨行分摊 |
| 来源与目的位置 | 原有位置选择业务组; 目的子库位仅在原 move 目的范围内、对唯一已选且已扫行改位, 不加数量、不改其它行 |
| 冻结、公司与容量 | 跨公司/越界、冻结/禁止入库、存储类别或容量不满足时拒绝; 已装箱明细不能单独换位 |
| 批次与序列号 | 缺追踪进入待补扫, 未补齐不计数; 不把上一商品的追踪上下文带给另一商品 |
| 组与分页 | 页面/行归属保持准确, 操作定位使用服务端返回组; 切页不构成库存动作 |
| 验证与欠单 | 走原生整单或批次验证, 不把未扫量自动补齐; 警告、欠单及未开始批次成员按原生流程处理 |
| 装箱与 WCS | 只处理已确认范围, 保留人工能力授权和正式入口; 不重复装箱、不由 AI 直接发设备请求 |
| 失联与会话变化 | 未知结果先核对原事件, 过期/占用/外部修改停止继续写入; 接管需要明确操作 |
| AI 固定版本 | 当前会话固定正式策略快照; 新发布不静默改变旧会话; 纯试算不等于实际库存动作成功 |
| 查询与只读详情 | 首页产品/位置查询不创建库存作业或修改数量, 详情可查看层级及库存后返回 |

## 现场设备补充

使用真实 PDA/扫码枪和标签, 核对键盘布局、输入法、前后缀、连续扫描、焦点、休眠唤醒、浏览器返回和相机权限. 用实际行数、位置/包裹分组和仓库网络测量性能, 不用固定演示数字代替现场吞吐.

声音/震动不可用时仍应有可读的结果; 失败时暂停依赖事件, 不沿用错误位置. 扫码、向导和验证期间的队列行为按当前工具实际结果核对. 已记账库存的纠正使用原生后续单据流程, 不恢复整份旧快照.
