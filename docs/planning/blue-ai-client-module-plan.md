# blue_ai_client 模块与设置

日期：2026-10-13。状态：已开发并安装到开发库；本文件替代首版建议方案。

- 模块技术名 `blue_ai_client`，显示名称“宝蓝 AI 云端连接”，独立扩展 MuK，不修改上游核心。
- 使用 Chat Completions。默认模型 `glm-5.3-Flash`，业务用户 Key 由代理识别用户身份。
- 团队固定 `odooAI`，任务固定“日常任务”；管理员在每个 Odoo 用户的连接里填写 Agent 名称和其业务用户 Key。不是所有用户共用一个云端 Agent 或 Key。
- 设置在 MuK AI → 设置 → 宝蓝云端服务。连接地址/模型共用 provider；Key/Agent 按用户保存。无剩余额度展示。
- 用户连接在 MuK AI → 配置 → 宝蓝用户连接；代码会话在报表下。
- 使用代理返回的选择表单自动初始化，按名称匹配且保留选项标识；未公开 Metadata API，不猜测名称对应的 ID。
- 业务资产页面“AI 生成 / 修改”打开 MuK 聊天。读取实际资产→云端生成→专用工具保存草稿→本地试算验证→用户发布。
- 首期由 MuK 主持本地工具循环；云端负责知识/技能注入和模型调用。没有另建云端任务编排循环，避免重复执行。
- Key 管理、停用连接、用户身份隔离和业务权限均由服务器检查。所有写入限制在当前资产；正式版本和草稿变化都会拒绝旧会话覆盖。
- 首期不拆 blue_ai_memory/blue_ai_skills/blue_ai_license，也不复制现有资产发布系统。

使用说明见 [模块 README](../../blue_ai_client/README.md)；验证记录见 [交付记录](../third-party/blue-ai-client-install-2026-10-13.md)。
