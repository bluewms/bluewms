# BlueWMS20 当前计划

更新: 2026-10-26。基础开发已具备,后续以部署验证、现场适配和交付巩固为主。模块与版本见 [架构](../module-architecture.md)。

## 已实现基线

库存基础/硬约束、上架增强、独立盘库及 ERP 关联、四类 ERP 接口、WCS /4、设备 /1、PDA 条码与条码 /1、代码资产及五类 AI 草稿流程均已有源码和对应验证入口。使用见 [业务指南](../README.md)。实例安装、知识批准和实机验收分别确认,不因文件存在就视为现场交付。

## 后续工作

| 事项 | 验收出口 |
|---|---|
| 知识完善与发布 | 六库准确内容、合同、批准页与正文摘要一致,真实业务身份可检索读回 |
| 安装/升级与跨机器交付 | 数据库与附件可恢复,人工参数/草稿/正式版本/库存/在途任务可核对 |

| 尚未纳入的扩展 | RFID/EPC、报废附加页、空载具池/自动拆包及客户专属流程单独评审 |
| 产品发布与运维 | 确定发行清单、版本、升级说明和监控,再建立正式 Release |

WES 专用模块已退役,旧实例按 [升级步骤](../operations/upgrades.md) 处理。旧客户数据、XML ID 和在途任务不随源码更名自动迁移。客户差异放 `blue_project_*`,共性能力回标准模块。

## 固定约定

固定服务负责准入、数量、公司/权限、设备授权和状态机。AI 只在本机合同范围内生成与验证草稿,用户发布;已固定业务按原版本执行,回滚不撤销物理动作。项目共用五个业务 Task 和一个日常 Task,用户保留自己的 Key/Agent。准确知识只维护 docs/wiki,上传与 Git 合并分别执行。

开发前继续读取 [开发规则](bluewms-development.md),修改通过任务分支与 PR,main 使用 squash 合并。
