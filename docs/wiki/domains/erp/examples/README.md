# ERP 接口需求示例

知识状态：`planned`。更新：2026-10-17。这里是需求设计输入，尚无已验证 AI 可执行代码或测试 schema。

| 候选知识 ID | 需求 | 业务输入与预期 |
|---|---|---|
| `erp.inbound_mapping` | 外部入库单转本地待处理单据 | 给出外部单号、商品编码、数量及单位，按明确字典映射；缺少单位映射时拒绝该行并说明 |
| `erp.duplicate_document` | 重复推送不重复创建 | 相同外部单据／行标识再次收到相同内容时不重复建单；差异按明确更新规则处理 |
| `erp.unknown_product` | 未知商品不靠猜测创建 | 商品编码不存在时返回诊断；是否允许建主数据由固定业务授权流程决定 |

实现合同后，每个案例从 [模板](../../../templates/example-template.md) 复制成独立文件，补准确代码、输入／期望、验证和来源，达到 verified 再加入批准示例。规范见 [ERP 规范草案](../specification.md)。
