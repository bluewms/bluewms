# 条码扫描需求示例

更新: 2026-10-21. [分隔二维码案例](delimiter-qr.md)及 barcode_policy/1 已有本地准确验证,云端批准与发布单独进行. 以下其他案例仍为需求候选,不能当成已交付运行代码.

| 候选知识 ID | 需求 | 业务输入与预期 |
|---|---|---|
| `barcode.location_first` | 先扫描目的库位再确认货物 | 未确认库位时扫描货物给出明确提示；确认后按本地业务校验继续 |
| `barcode.product_batch` | 条码含商品与批次号 | 按明确编码规则解析，校验必填与商品／批次关系；无法识别时不猜测 |
| `barcode.pallet_consistency` | 托盘扫描与当前作业一致 | 托盘不属于当前允许范围时拒绝；重复扫描不重复确认数量 |

合同和前端能力明确后，用 [模板](../../../templates/example-template.md) 为每项创建独立案例，补解析输入、状态转换预期及前后端验证。规范见 [条码规范草案](../specification.md)。
