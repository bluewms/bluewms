# 基础说明：项目与知识分工

状态：现行约定。更新：2026-10-17。维护者：BlueWMS 维护者。

## 项目范围

BlueWMS 基于 Odoo 20、MuK 与宝蓝自研模块。模块平铺在 `bluewms/`，自研命名为 `blue_<领域>_<功能>`；库存、WCS 和条码分别归属对应领域。标准模块负责稳定业务流程，AI 通过已开放的合同生成补充代码，人工审核后才发布。

五个 AI 入口是上架、ERP、WCS 生成、设备连接、条码扫描。当前只有上架开放 AI 草稿读取、提交和验证；其他领域分别看 [总目录](../README.md) 的状态，已有业务功能不等于已经接入 AI。

## 各位置保存什么

| 位置 | 保存内容 | 使用方式 |
|---|---|---|
| 本目录与 Git | 人工可审阅的基础说明、规范、案例来源、验证证据索引及历史 | PR 修改，保留版本；不是 Odoo 的运行时知识库 |
| 云端 Wiki／Skill | 批准的业务知识、案例和生成经验，含正文、来源、版本与适用范围 | 按用户／Agent 权限读取；新经验先作候选再审阅发布 |
| 本地 Odoo 数据库 | 当前草稿、准确代码、本次测试、不可变代码版本、发布回滚及执行记录 | 真实业务使用本地正式版本；聊天摘要不能代替准确代码 |
| 本地正式模块 | 运行合同、解释器、原生业务校验、固定接口与权限 | 生成前返回真实能力，本地继续强制执行 |
| Code Graph（可选） | 指定仓库、分支和提交的源码结构、符号及调用关系索引 | 辅助定位与影响分析，不能代替当前数据库资产或当前工作区源码 |
| 私有运维目录 | Key、配置、数据库／附件备份及原始排错材料 | 不进入公开 Git、Wiki、Skill 或提示词正文 |

“本地准确代码”是当前绑定策略资产的代码，不是读取本机安装的全部 Odoo 20 源码。当前读取工具返回草稿全文、需求、测试、合同、摘要和正式版本 ID；它不自动返回所有正式版本全文，也不扫描整个 addons 目录。

当前上架生成依靠本地合同和云端批准示例，Code Graph 是后续源码理解能力。若建立图谱，建议以项目 `main` 的批准源码为基础，合并 PR 后同步并核对提交；不同版本的官方 Odoo 源码单独管理。图谱查询桥接尚未接入当前 Odoo 助手。

## 始终保留的原则

- 原生系统设置和公司权限优先，补充代码只在合同允许范围内增加限制或选择。
- 草稿、试算、发布与执行分开；AI 无发布工具。发布和回滚由本地授权用户操作。
- 通用知识按团队共享，个人原始聊天／画像按用户与 Agent 私有；五类业务按 Task 分类。
- 自动提炼区分事实、测试、规划和推测，不从单句话构造职业、人格或永久偏好。
- 知识更新不会自动修改正式代码；回滚代码版本不会撤销已经完成的库存移动。
