# ERP 接口首版交付

日期：2026-10-20。模块：`blue_erp_interface`，版本 `20.0.1.0.0`，合同 `erp_mapping/1`。本版采用已确认的三个约定：库存单验证完成触发、部分完成按本次实际数量累计反馈、盘点只发送差异。

菜单调整版本 `20.0.1.0.1`：入口位于设置顶部“技术”右侧，点击“ERP 接口管理”直接进入业务接口列表，ERP 连接、关联单据、同步记录与外部操作通过列表顶部按钮进入。

## 当前范围

ERP 接口管理下分为 ERP 连接、业务接口、关联单据、同步记录及外部操作。可以创建多条入库／出库／内部调拨／盘点接口，每条独立维护需求、代码、试算、版本和发布历史。连接密钥与接收令牌仅系统管理员可读写，库存管理员维护业务接口和代码。

ERP 主动 POST JSON 至 `/blue_erp/v1/interfaces/<id>/documents`，Bearer 凭据验证成功后，使用人工指定的有效库存执行用户，在单一公司范围内解析和建单。AI 输出标准单头／明细、允许范围内的位置和分组键；固定服务创建并确认原生库存单，调用原生预留。出库缺货保持原生等待状态，不伪造库存。

首版使用已有唯一商品编码及库存单位原始名称（lang=None），已有明确批次／往来单位。未知、重复或跨范围映射拒绝；整批建单在一个保存点中完成，后续行失败不会留下前面的半张单。相同接口／外部单据 ID／标准内容返回原结果；变化内容要求人工核对。外部单头和行 ID 均使用文本。

库存验证完成后，原单及欠单分别入队，保留来源版本、实际数量、累计数量、当时已反馈量及稳定事件键。固定服务校验公司、作业类型、批准位置、商品／行、显式批次和累计数量；每次部分完成按本次实际量反馈。

盘点接入原生 `stock.quant._apply_inventory()`，明确选择公司内准确内部库位，发布后启用。锁定库存后保存账存、实盘、差异、批次、包裹和货主快照，再走原生库存调整；零差异不产生事件。一个库位只对应一个启用接口，不自动包含子库位。本版不迁移旧独立盘点应用。

## 发送和恢复

AI 代码只引用人工配置的操作代码；每个操作对应批准的同服务相对路径，固定发送器执行 JSON POST，凭据在本地替换。代码不读取密钥、不自行联网。共享解释器从现有设备协议抽到 `blue_extension_contract/tools/json_policy.py`，保留原 AGPL 文件许可和兼容导入，ERP 不依赖 WCS。

同一事件的多个操作按顺序执行，同一来源单据的事件保持顺序。固定服务维护稳定 Idempotency-Key，ERP 端仍需支持幂等。发送前用独立事务持久化 sending；进程中断、超时、非 2xx 或响应不明确时保持待核对，禁止自动重发。成功步骤保留，后续步骤失败不重发前面的成功步骤。

只有库存管理员填写说明，明确向 ERP 核对后，才能标记成功或确认未处理后重新排队。所有处理保留本地操作历史。WMS 库存完成不等待网络调用，ERP 状态单独显示。未完成单据或未结束事件存在时，连接和业务范围不可更换；可以发布新代码供后续单据使用，已有单据固定原版本。

## 验证

- 隔离 `bluewms20_erp_v1_test`：ERP、设备协议、AI、上架、WCS 扩展共 289 项回归通过，0 失败、0 错误；权限检查完善后再次执行 ERP 34 项定向回归，0 失败、0 错误。
- 云端网关源码：16 项单元检查通过，包括 ERP 合同需要实际批准元数据后才能开放。
- Wiki：17 个案例、50 条准确试算及完整合同／内部链接核对通过。
- 持久发送集成：真实隔离数据库独立事务、模拟 ERP；两路接收在旧事务快照下并发推送，经原生事务重试后只建一份单据；两个步骤有序执行，重入发送器不重复发送；模拟发送进程崩溃后 sending 仍持久化，过期转待核对且不重发。
- HTTP：接收鉴权、指定执行用户、重复返回和整批失败回滚；本轮不向真实 ERP 发送请求。
- AI 工具：模拟批准 Wiki，实际运行绑定／读合同／读页／提交草稿／验证工具；不能将其称作真实模型生成或真实云端检索验收。

## 安装与现场边界

先备份主库数据库和同一时点 filestore，检查归档可读及内容并记录库存、资产、人工参数及在途任务基线，再安装 `blue_erp_interface`，升级 `blue_extension_contract`、`blue_wcs_protocol`。不会创建示例 ERP 连接或发布任何业务代码；安装后人工配置并试算发布。

首版暂不包含定时拉单／分页、水位维护、金蝶 SDK、动态认证、响应驱动的后续字段注入、原单变更／取消、跨公司调拨、自动单位换算或超量履行。E10／金蝶旧案例用于方案参考，现场接入须另做准确报文及真实联调。

本机主库已安装此版本，并升级共享合同与设备协议模块。安装前后核对库存、原有代码资产、人工设备配置和 WCS 任务摘要一致；ERP 连接与业务接口数量均为 0，等待人工新建配置。主库未安装测试夹具或发布示例代码。备份与原始验证记录留在私有运行目录。
