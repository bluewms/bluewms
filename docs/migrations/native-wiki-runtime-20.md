# 原生 Wiki 与五类 Task 接入

日期：2026-10-18。模块：`blue_ai_client` 20.0.1.4.0；配套云端只读通道独立于腾讯原容器，代码在 `docs/cloud/`，不随正式 Odoo 发行包交付。

本轮把正式 Odoo 工具从固定 Skill 正文切换到腾讯原生 Wiki，五类入口分别绑定同名云端 Task。知识发布来源仍为 `docs/wiki/`，准确代码、真实合同、本次测试、草稿与正式版本仍在 Odoo 保存。

## Task 问题的实际原因与修复

设置页的“日常任务”原本只描述普通聊天，但页面没有明确区分业务入口。早期曾出现代理仅有一个候选、直接选中“日常任务”的情况。因此，仅在本地写入 `blue_task_name` 并不能证明云端 Task 已正确选择。

首次接入误把 Task 创建者等于调用用户当作使用条件，为两个用户额外创建了十个重复业务 Task。后续按用户要求删除这十个，保留原有五个业务 Task 和一个日常任务；原有六个已关联三个用户的 Agent。现统一按团队共享使用，不再按用户创建 Task。

| 业务入口／hook | 云端 Task | 当前能力 |
|---|---|---|
| `putaway_policy` | 上架策略 | 从资产页生成并验证草稿；也可单独知识沟通 |
| `wcs_creation` | WCS生成策略 | 新生成仅 /4；从资产页生成并验证草稿；也可知识沟通 |
| `erp_mapping` | ERP接口 | 知识沟通，执行合同仍 planned |
| `device_protocol` | 设备连接接口 | 知识沟通，执行合同仍 planned |
| `barcode_policy` | 条码扫描策略 | 知识沟通，执行合同仍 planned |

业务请求先以真实业务 Key 验证用户、Agent 和对应 Task，明确发送代理已支持的预选身份头，并在 Odoo 会话保存实际云端绑定。缺失、重复、未关联或中途变化时拒绝继续，不悄悄选日常任务。普通聊天仍使用日常任务。

同日共享修正已删除新增的十个重复 Task，云端实际总数由 16 回到 6，原有任务及其 Agent 关联保持不变。三个用户的五类 HTTPS 身份解析共 15 项通过，均选择同一组五个业务 Task；本地 Odoo 五个入口搜索／读页冒烟通过，测试会话事务已回滚，网关回归 14 项通过。此次未重跑原 222 项 Odoo 模块测试；原代码生成验收仍按下方首次接入范围理解。具体结果见验收 JSON 的 `shared_task_cleanup`。

新用户只关联已有六个 Task，接入程序不创建任务。此前绑定被删除重复 Task 的会话保留原记录，请从业务页面新开会话，不静默替换历史绑定。此操作只删除重复 Task 及对应关联，不主动删除历史聊天、知识正文或 Odoo 代码资产。

## 页面入口

- 生成代码：上架／WCS 资产页的“AI 生成或修改”，继续使用浮窗。
- 五类知识沟通：**MuK AI → 宝蓝业务知识 → 对应业务**。这些独立会话没有资产写入工具；需要改代码时从资产页重新打开。
- 设置 → MuK AI → 宝蓝云端服务：显示五类 Task 对照，“日常任务”明确标为普通聊天任务。
- 会话记录可查看业务入口、云端业务任务、合同和绑定资产。

旧代码会话保留历史，不追溯改 Task、合同、知识来源或正式版本。请从资产页新开会话；普通历史聊天可继续按原日常用途使用。

## 生成流程

1. `blue_read_code_asset` 只返回绑定资产的真实代码、完整合同、测试、摘要及可用 Wiki 范围，不再拉取固定 Skill 文件。
2. `blue_search_code_knowledge(query)` 只搜索通用库及当前领域；腾讯负责检索，返回摘要和本会话的页面引用。
3. `blue_read_code_knowledge(page_ref)` 只读取本会话真实搜索命中的审阅页全文，冻结 Wiki／资产版本、来源提交、页摘要和合同。
4. 生成前完整读取通用规则、本领域规范与至少一个合同匹配案例；目录、模板和搜索摘要不能替代正文。
5. `blue_submit_code_draft` 先复核真实读资产标记、会话身份、草稿摘要／正式基础版本，再通过云端复核全部已读来源与批准状态，之后保存草稿及来源。
6. `blue_validate_code_draft` 使用原解释器验证本次代码与测试。发布仍由用户执行；业务运行不访问云端，断网时既有正式策略继续执行。

旧 `tencent_skill_bridge` 引用不伪装为新 `tencent_wiki`；旧不可变版本保留其原引用。搜索结果映射与知识引用字段禁止直接 RPC 改写。资产与不可变版本只保存知识引用；MuK 聊天按原机制保留实际工具输出供对话回放，这些记录不作为独立示例库，也不能用作断网兜底。已读页最多 12 个、累计 192 KiB，单次响应／超时有界；不用截断代码或测试的方式规避预算。

## 云端接入边界

Odoo 使用原有 HTTPS 模型域名和当前业务 Key。云端 `/odoo-wiki/v1/` 只负责鉴权、范围与版本校验，内部调用腾讯标准发现／搜索／读页工具；不复制示例到 Skill、不实现另一套检索。服务管理凭据仅留在云端专用账户可读的私有文件。

每次检查当前 Core ACL、用户／Agent 绑定、索引 ready、批准状态、合同及批准页白名单；读页核对完整摘要与前后 Wiki 版本。后三类 candidate 资料只允许无执行合同的知识沟通。知识不足或服务异常时报告失败，不回退旧 Skill、本地示例或其他领域。
