# WCS 基础创建及 AI 创建配置实施设计

> 历史/3草案与暂停记录保留。2026-10-18后续业务澄清已通过/4实施并部署; 当前以 docs/design/wcs-v4-validation.md 和 docs/knowledge/wcs-ai-creation-v4-zh.md 为准。

> 状态: 待业务语义确认的本地实现草案。已在隔离库技术验证, 未部署到开发主库, 未经业务批准, 不应直接作为已批准云端知识发布。用户正在继续解释原代码的业务含义; 后续实现及部署已暂停。

日期: 2026-10-18。实现合同: wcs_creation/3。

- 无 AI 绑定: 每条正数量移动行一个直达货物作业, 使用该行起终点及人工设备/任务类型; 入库实际确认, 非入库有效预留。旧生成条件/模式/数量/容器字段保留数据库兼容, 不控制新创建。
- 有 AI: 本地受限代码分 configure/tasks 两阶段。configure 决定 condition、mode、quantity_basis、group_by_container; 再按策略分组、检查库存和覆盖量, tasks 输出最多四步。空列表表示条件等待。无需在线模型。
- 人工边界: 总启用、入出方向、主设备类别/设备/任务类型、附加设备/任务类型授权、自动执行、自动验证和验证前必需作业。AI 不能改写。额外设备只允许显式选择的接力设备。
- 顺序: 权限/单据状态 -> 选择固定或正式策略 -> configure -> 分组 -> 覆盖与在途检查 -> 库存/冻结/整载具检查 -> tasks 合同校验 -> 点位及适配检查 -> 固定版本、计划、行数量和准确报文。
- 幂等: 未取消计划持续覆盖原行数量; 不因整单有作业而跳过其他行。载具在途时等待, 其他载具/散件行继续。已完成搬运不能为同一实物补下第二次搬运; 原明细不可改写, 新明细独立补齐。取消未发送完整计划后可新建修订。
- 无载具: simulation 支持逐行; JSON 网关需管理员确认支持无容器货物; HIK/WES 当前协议不宣称散件支持, 明确报错。整载具多行逐行搬运物理冲突明确报错, 使用容器策略或人工拆分载具; 不漏行、不重复搬运。
- 兼容: /1、/2 历史解释器及固定任务/报文保留。新计划仅接受 /3; 不自动发布或激活旧合同。新增 /3 模板, 不覆盖旧模板合同和正式快照。旧绑定提示人工创建新版配置或取消绑定使用基础路径。
- 失败: 合同/授权/冻结/数量错误中止事务; 未确认、已覆盖、载具在途和条件不满足显示等待。预览只读, 不锁定、不创建、不发送。
