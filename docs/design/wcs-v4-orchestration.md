# WCS /4: 全部基础行增强与任务程序编排

/4不再以四个Selection设置代替策略: lines阶段看到全部正数量行与公司/库存/确认/载具/覆盖信息, 为每行输出create/wait/exclude、数量/分组/位置来源/原因。创建前分组和系统复核。tasks阶段看到分组完整货物、位置来源和人工授权设备, 生成最多四个程序步骤。repeat是显式同数据后续程序, relay是连续接力; 两者都默认且强制等待上一货物步骤end, 空载具配合仍支持点位/取货事件。

一个计划只存一份商品数量。每个设备步骤有独立身份、序号、报文及回调。库存验证在所有步骤完成后执行一次。排除WCS的行在固定策略决策快照中保存货物/数量/位置指纹, 等待行不能被排除豁免。设备物理位置映射记录来源, 库存仍按原行记账; 单据位置必须包含原库存位置且适配设备明确支持范围。设备实际回报与既定库存明细不一致时暂停核对, 不自动改写库存。

满载无隐含标准。暴露同载具全部已拣选、同单位数量、基于产品基础单位的重量/体积及完整性、包装类型max_weight。策略可表达显式阈值; 基础数据缺失返回完整性false, 标准示例等待。整载具实际库存完整性仍固定复核。

保留/1-/3历史及解释器。/1以原线路候选执行原代码, 候选须匹配人工设备/模式/库存范围, 不自动发布或改变绑定。新/4基础运行定义独立新增且不含示例正文, 无AI新计划走/4基础路径; 已固定旧单据按原合同继续。旧/2正式绑定以原设置构造兼容候选, 限制人工设备/任务类型后继续可用, 不自动改绑/发布。开发主库升级前备份, 比较库存、人工设置、草稿、版本、发布与任务指纹, 更新后切回工作目录源码挂载。
