# 盘库单与实盘

适用模块: `blue_stock_inventory`；可选 `blue_erp_inventory`、`blue_barcode_inventory`。更新: 2026-10-26。

## 操作步骤

1. 库存 → 盘库，新建盘库单，选择本公司内部库位及负责人。
2. 选择是否包含子库位，以及商品、分类子树、批次/序列号、包裹和货主范围。
3. 管理员开始盘库，建立账存快照；负责人录入并确认实盘。可用账存预填、零预填或空白盘点，预填不代表已盘。
4. 可逐行应用，或由管理员完成整单记账。全部明细记账后自动完成。

盘库以商品、库位、批次、包裹、货主的完整维度保存账存、实盘和差异。无库存明细先建立零基数，应用时通过原生库存调整记账，不直接把实盘写成 quant。

## 保护与并发

- 进行中范围检查重叠，包含空库位；重复完成只允许一次有效调整。
- 原生业务仍可发生。应用前锁定并核对账存；账存变更时先刷新并重新确认，不能用旧实盘覆盖新库存。
- 已应用明细、快照及关联流水不可直接改写/删除；已有记账记录不能取消或退回草稿。
- 商品库存单位固定，不自动换算单位或创建批次。同一维度有多条未整理 quant 时先原生整理。
- 冻结、禁止入库和非负库存规则继续生效。零差异保存确认，不额外产生 ERP 事件。

## 条码与 ERP

条码入口必须选择已开始的盘库单。默认逐枪累计，支持明确总数及零实盘；只保存实盘，管理员仍从盘库单记账，见 [条码作业](barcode.md)。

ERP 链接模块以真实盘库身份关联差异事件，逐行保留来源键和调整前快照；客户端默认值不能伪造盘库关联或跳过发送队列，见 [ERP 接口](erp.md)。

旧盘库业务数据、机器人盘点和客户设备流程不因安装本模块自动迁入。安装/升级及恢复要求见 [运维步骤](../operations/upgrades.md)。
