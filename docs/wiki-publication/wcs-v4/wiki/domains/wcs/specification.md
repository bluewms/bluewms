# WCS /4 AI生成规范

hook: `wcs_creation`。本地实现与精确用例verified, 只读桥接已就绪, 云端专用批准资料待用户最后写入。更新: 2026-10-18。完整规范、字段与代码见[独立知识文档](../../../knowledge/wcs-ai-creation-v4-zh.md), [机器可读合同](../../../knowledge/wcs-creation-v4-contract.json)及[精确用例](../../../knowledge/wcs-ai-creation-v4-examples.json)。

当前模型为全部有效基础行 -> 逐行create/wait/exclude、数量依据、容器/路线分组、行/单据物理位置映射 -> 建立第一任务定义并可追加同数据repeat双/多程序 -> 上一goods完成后下发下一goods -> 计划数量/库存记账一次。无AI逐行路径独立可用。

人工WCS类型/设备类别/设备/任务类型及自动开关不可改写。入库实际确认、合法库存/预留、公司/冻结、整载具实际货物完整和幂等仍强制。picked的行/载具/整单范围与显式装载阈值分开。/4输出expected_result, 旧/1-/3历史不自动转换。

AI与上架共用浮窗和会话绑定, 但读取WCS时要求同项目Skill的01/06/07批准资源及Wiki来源, 不读取上架03/04、不回退本地示例。当前云端未写入, 应返回明确缺失错误。按真实本地contract_schema生成, 保存并验证草稿, 人工发布。新建/4资产使用WCS生成策略Task; 旧WCS合同需人工选择新资产, 不自动改绑。
