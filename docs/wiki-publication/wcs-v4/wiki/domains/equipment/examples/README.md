# 设备接口需求示例

知识状态：`planned`。更新：2026-10-17。未定义 AI 执行合同，不含可直接运行的通信代码。

| 候选知识 ID | 需求 | 业务输入与预期 |
|---|---|---|
| `equipment.status_mapping` | 厂商状态转内部状态 | 按明确版本字典解释状态码；未收录状态返回未知，不猜测已完成 |
| `equipment.duplicate_callback` | 重复完成回报只处理一次 | 同设备／任务／事件标识重复到达时保留一次有效状态转换与审计 |
| `equipment.disconnect` | 断线后的任务处理 | 按固定适配器确认连接及任务状态，无法确认时保持待核实，不自动当作成功 |

将来每个案例从 [模板](../../../templates/example-template.md) 单独建文件，增加经脱敏的报文、准确映射、期望、模拟验证及来源。Key、真实连接地址及凭据不写进案例。规范见 [设备规范草案](../specification.md)。
