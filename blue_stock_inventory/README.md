# 库存盘点

Odoo 20 的独立人工盘点模块，迁移自 bluewms19 的 `stock_inventory_ajustement`。入口：库存 → 盘库。原作者、许可证及准确来源见 [NOTICE](NOTICE.md)。

## 使用

1. 新建盘点单，选择本公司内部库位，可包含子库位；按全部商品、指定商品、单一商品、分类或批次筛选，也可限定包裹及货主。
2. 库存管理员开始盘点。系统按商品／库位／批次／包裹／货主建立账存快照；空白盘点允许管理员手工添加明细。开始和录入不会直接改实际库存。
3. 负责人录入实盘数量，或明确确认预填数量。预填账存或零都不自动代表已确认；序列号数量只能为 0 或 1。
4. 库存管理员完成盘点，或逐行应用已确认数量。通过原生库存调整产生差异流水，保存本单及本行的准确关联。账存变化时先刷新并重新确认实盘。
5. 查看实盘快照、调整流水和完成时间。已有记账明细及流水不可改写、删除；更正使用新的库存调整。未记账的进行中盘点可以取消或退回草稿。

库存设置可启用“盘点全部记账后自动完成”。同一范围的重叠盘点会阻止启动；不同商品、批次、包裹或货主的明确独立范围可以并行。进行中的范围禁止从原生数量调整旁路应用，正常库存作业仍可发生，并通过账存冲突要求重新盘点。

## 边界

只依赖 stock 和 mail，不强制安装 ERP、条码、WCS 或机器人。与 ERP 同时安装时，独立链接模块 `blue_erp_inventory` 自动关联盘点单和差异事件，继续使用持久发送队列；盘点完成时不联网。

库存单位固定为创建明细时的商品库存单位；更换单位须重新建立明细。显式批次需要已存在。相同库存维度存在多条尚未整理的 quant 时，要求先用原生库存整理再刷新账存，不任选一条记录改数。

这是新 Odoo 20 模块的安装迁移，不会自动读取旧 19 客户数据库。条码及机器人模块仍待独立适配，不能直接安装旧接口模块。
