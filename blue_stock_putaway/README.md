# 上架增强策略

Odoo 原生上架规则先检查范围、优先级、容量、重量、混放、托盘、冻结及公司权限；本模块只在准入候选内继续过滤／排序。整托不拆，跨产品批次号按文本比较，同单集中不承诺全局最优或独占。

从库存 → 配置 → 上架策略管理资产，人工或通过原生 Wiki 生成并验证草稿后人工发布，再在原生上架规则选择“增强策略”。版本按作业单＋规则固定，旧单据不因改绑／发布而改变。

通用示例不在生产数据库安装，正式执行不需要模型在线。三个准确案例维护在云端，Git 只保存审阅来源。用法、回退及迁移边界见[上架说明](../docs/guides/putaway.md)，AI 工具及五类 Task 见[原生 Wiki 接入](../docs/guides/ai.md)。
