# BlueWMS 条码盘库

依赖 blue_stock_inventory 和 blue_barcode_base. 从进行中的盘库单进入,或在条码首页选择本人有权操作的进行中单据. 扫码只写本单实盘明细,不直接改 quant、生成移动或完成记账.

未确认行首次扫码从 0 累计,不会把账存预填值加进去. 已确认行继续累计,支持明确的实盘总数和实盘 0. 完整库存维度、负责人、序列号 0/1、已记账禁止修改及账存冲突保留核心约束. 同一盘库单的写入终端通过会话占用和明确接管协调.

盘库完成仍由库存管理员在原盘库单应用. ERP 差异沿用现有桥接;扫码不另造 ERP 事件. 包裹扫描仅定位,不会把账存包裹内容自动当作实盘数.
