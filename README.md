## 二、核心产品：BlueWMS 仓储管理系统（WMS）

### 2.1 产品定位

**BlueWMS** 是宁波宝蓝物流科技有限公司基于开源平台开发的一体化仓储管理解决方案，定位为 **"自动化仓储管理系统"**。

**核心亮点：BlueWMS 特别适合用于 AGV、四向车等自动化系统中的仓储管理。** 系统内置 WCS 自动化控制执行模块，通过底层协议与 AGV、四向车、智能柜、自动化立体仓库等设备深度对接，实现仓库作业单自动转换为自动化设备执行工单，达到系统与自动化设备的相互控制与执行。\[pdf\_2]\[pdf\_1]

### 2.2 技术架构

| **项目**  | **内容**                                                                      |

| 开源许可证   | 基础版GNU Affero 通用公共许可证（AGPL）第3.0版                                            |

| 操作系统支持  | MacOS、Windows、Ubuntu                                                        |

### 2.3 系统组成

| **模块**            | **说明**                               |
| ----------------- | ------------------------------------ |
| **BlueWMS 核心系统**  | 提供完整的仓库管理功能                          |
| **BlueWMS+ 增强系统** | 适应自动化搬运与仓储的加强版，适用于 AGV、四向车等自动化设备集成场景 |
| **WCS 自动化控制执行**   | WCS 执行单据管理 + 自动化设备及接口管理 + MQTT 协议支持  |

### 2.4 核心功能模块

#### 物流路线与仓库调配

| **功能**  | **关键提升** | **说明**                                                  |
| ------- | -------- | ------------------------------------------------------- |
| 多仓库与调配  | 30%↑     | 管理多个仓库和库位，优化仓库布局和存储方案                                   |
| 作业类型自定义 | 60%↑     | 收货、上架、拣选、波次、越库、盘库、交货等可自定义配置；每个作业可配置关联库存位置、产品包装包裹、WCS设备等 |
| 路线可配制   | 50%↑     | 灵活定义和配置物料流动路径，确定最佳物料流转路径                                |
| MRP管理   | 40%      | 管理产品物料供应计划与策略，同时实现ERP基本功能                               |

#### 库存管理

| **功能**   | **关键提升** | **说明**                                            |
| -------- | -------- | ------------------------------------------------- |
| 数量复式记账   | 70%↑     | 每笔交易记录在两个位置中，易于发现错误与防止欺诈                          |
| 库位与分配策略  | 30%↑     | 实时监控库存，支持产品/包裹容器/WCS三种类型的上下架规则，满足不同货架与自动化设备库位分配策略 |
| 产品包装与包裹  | 40%↑     | 自定义多种包装管理                                         |
| 批次与系列号管理 | 50%↑     | 质量控制、追踪与精确库存管理                                    |

#### 其他功能

* **显示大屏 Dashboard**：多屏多用户、可定制、实时数据更新
* **条码作业**：提高效率、减少错误、实时跟踪与精确库存管理
* **功能全覆盖**：多仓库管理、多路线作业管理、产品包装、托盘容器管理、批次系列号管理、库位管理、上下架规则与分配、出入库作业、盘库作业、越库作业、批量波次作业等

### 2.5 自动化设备对接能力（核心优势）

**BlueWMS 最大的差异化优势在于：系统从底层架构设计就充分考虑了与自动化设备的深度集成，特别适合 AGV、四向车等自动化系统中的仓储管理。** \[pdf\_2]

#### WCS 自动化控制执行模块

| **能力**         | **说明**                                                              |
| -------------- | ------------------------------------------------------------------- |
| **WCS执行单据管理**  | 为WMS单独开发的WCS执行模块，对WCS自动化执行工单进行记录与管理；用户可自定义分组创建WCS执行工单界面             |
| **自动化设备及接口管理** | 可单独创建管理多种自动化设备（AGV、四向车、智能柜等）的接口，并关联到仓库的自定义作业中，实现仓库作业单快速转换为自动化设备执行工单 |
| **MQTT物联网协议**  | 系统自带标准MQTT协议，可快速远程与不同网络环境下支持MQTT的设备进行通信，实现系统与IO信号开关的输入输出            |
| **系统与设备相互控制**  | 达到系统与自动化设备相互控制与执行，实现端到端的自动化仓储作业闭环                                   |
