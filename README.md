## 二、核心产品：BlueWMS 仓储管理系统（WMS）

### 2.1 产品定位

**BlueWMS** 是宁波宝蓝物流科技有限公司基于开源平台开发的一体化仓储管理解决方案，定位为 **"自动化仓储管理系统"**。

**核心亮点：BlueWMS 特别适合用于 AGV、四向车等自动化系统中的仓储管理。** 系统内置 WCS 自动化控制执行模块，通过底层协议与 AGV、四向车、智能柜、自动化立体仓库等设备深度对接，实现仓库作业单自动转换为自动化设备执行工单，达到系统与自动化设备的相互控制与执行。\[pdf\_2]\[pdf\_1]

### 2.5 自动化设备对接能力（核心优势）

**BlueWMS 最大的差异化优势在于：系统从底层架构设计就充分考虑了与自动化设备的深度集成，特别适合 AGV、四向车等自动化系统中的仓储管理。** \[pdf\_2]

#### WCS 自动化控制执行模块

| **能力**         | **说明**                                                              |
| -------------- | ------------------------------------------------------------------- |
| **WCS执行单据管理**  | 为WMS单独开发的WCS执行模块，对WCS自动化执行工单进行记录与管理；用户可自定义分组创建WCS执行工单界面             |
| **自动化设备及接口管理** | 可单独创建管理多种自动化设备（AGV、四向车、智能柜等）的接口，并关联到仓库的自定义作业中，实现仓库作业单快速转换为自动化设备执行工单 |
| **MQTT物联网协议**  | 系统自带标准MQTT协议，可快速远程与不同网络环境下支持MQTT的设备进行通信，实现系统与IO信号开关的输入输出            |
| **系统与设备相互控制**  | 达到系统与自动化设备相互控制与执行，实现端到端的自动化仓储作业闭环                                   |

#### 实际自动化对接场景

以某工艺品公司项目为例，BlueWMS 实现了以下自动化对接 \[pdf\_2]：

* **WMS + AGV**：WMS 下发任务给 AGV 调度系统，AGV 执行自动搬运
* **AGV + 电梯PLC**：与电梯 PLC 交互实现跨楼层运输
* **AGV + 码垛机PLC**：与码垛机 PLC 交互实现托盘回收
* **WMS + 条码枪**：自动上传数据至 ERP，减少 90% 沟通成本，系统自动提示库位，减少 30% 备货时间
* **WMS + 仪表板**：多数据源收集数据，多种图表展示，高度可定制、数据实时更新

> **核心理念**：ERP + WMS = 我要做什么 + 自动化辅助人工执行。ERP 下达出入库等单据，WMS 接收 ERP 单据指令，对货物进行管理，并通过 WCS 模块驱动 AGV、四向车等自动化设备执行作业。\[pdf\_2]

### 2.6 与ERP/MES的对比优势

| **对比维度** | **ERP系统**            | **BlueWMS**                             |
| -------- | -------------------- | --------------------------------------- |
| 功能深度     | 仅划分库区和库位，缺少过程校验      | 条码标识保障准确性，具备唯一性管理和批次管理                  |
| 响应时间     | 缺少条码硬件配置，需手动输入       | 扫描实现库存管理，提高效率和准确率                       |
| 自动化对接    | 无原生自动化设备对接能力         | 内置WCS模块 + MQTT协议，原生支持AGV、四向车等设备         |
| 适用范围     | 适用于种类批次不多、出入库频率不高的公司 | 适用于种类批次多、出入库频率高、追溯性要求高、**需要自动化设备集成**的库房 |

> **结论**：ERP/MES与BlueWMS是相辅相成的关系。ERP负责信息管理和资源规划，BlueWMS专注仓库管理并驱动自动化设备执行，三者通过集成实现协同。\[pdf\_2]

3. **丰富接口**：提供API与ERP/MES系统集成，MQTT协议与AGV、四向车等智能物流设备对接
4. **容器安装**：多操作系统支持，保证环境一致性与扩展更新

## 三、配套产品：WCSLink — 仓储自动化控制执行与互联系统

**WCSLink** 是一款专为仓储和物流管理打造的仓库自动化控制执行与互联系统，致力于解决上位系统与智能设备（AGV调度系统、四向车、智能柜等）之间的复杂对接难题，实现全系统协同。\[pdf\_4]

### 多协议支持

| **协议** | **用途**                              |
| ------ | ----------------------------------- |
| HTTP   | 标准客户端-服务器通信，如与ERP系统传输数据             |
| MQTT   | 轻量级发布/订阅协议，适用于物联网设备通信（AGV、传感器、告警灯等） |
| SOAP   | 基于XML的协议，确保WMS/MES系统间数据完整性和安全性      |
| Modbus | 专用于设备层通信，确保低延迟与高可靠性                 |

### 核心能力

* **标准化接口设计**：统一接口标准，显著缩短集成周期
* **弹性扩展能力**：兼容多种通信协议，无缝对接新设备或系统
* **快速部署与对接**：丰富的接口预设模板，已完成主流ERP、WMS、MES等系统及仓储自动化设备的模块化设计
* **任务优先级分配**：根据实时数据动态调整任务优先级，自动分配智能柜与AGV等设备任务
* **设备可视化管理**：实时监测设备状态，数据可视化输出
* **智能调度**：减少设备空闲和不必要移动，提升整体仓储运营效率
